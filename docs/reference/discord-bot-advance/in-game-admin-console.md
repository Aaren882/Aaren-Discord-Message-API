# 🎮 In-game admin console

## :shield:Sensitive Info

{% hint style="info" %}
It may contain some personal information. Be aware; don't let other people that you don't trust grant admin permission.
{% endhint %}

It's a panel where you can control the connection and see the current details of current extension has.

Once you're login-ed as an admin on MP server **`Discord Admin`** tab will show up in the map diary section.
