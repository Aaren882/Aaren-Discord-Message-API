These are template files to help beginners set up the webhook extension on server.

- Check the full documentation "https://aarens-base.gitbook.io/aarens-base-docs/aarens-discord-message-api/reference/reference" for further instructions.

# If you're using v2 webhook
- Drag them out to "Discord_Message_API" folder, so the extension can find them.
- These templates are only created when the extension is loaded. If you lose them, you can always find them in the documentation.

Please check the documentation for the most up-to-date information.
